# 本地通用资料库

独立运行的中文资料管理工具：创建资料库、上传文本、查看处理状态、预览原文、关键词检索和删除。参考 [Yuxi](https://github.com/xerrors/Yuxi) 的文档生命周期与来源展示设计；**本项目自行存储和处理资料，无需部署或连接 Yuxi 后端**。

与原项目的关系及具体改动见 [与 Deep Research 的差异说明](CHANGES_FROM_DEEP_RESEARCH.md)。

## 启动

安装 **Node.js 24 或更高版本**，下载或克隆本仓库，在仓库目录打开终端：

```sh
node server.mjs
```

不需要 `npm install`、Docker、模型 API Key 或向量数据库。打开 <http://127.0.0.1:4184/>，首次设置自己的本地用户名与密码。没有默认密码。服务只监听本机，按 Ctrl-C 停止；不会自动开机运行。

macOS/Linux 也可运行 `./start.sh`，Windows PowerShell 可运行 `./start.ps1`。脚本受系统策略限制时直接使用 `node server.mjs`。Windows/Linux 实机状态见 [验收记录](docs/ACCEPTANCE.md)。

## 第一次使用

1. 设置本地账户（密码至少 10 个字符），然后创建资料库。
2. 上传 UTF-8 编码的 `.md` 或 `.txt` 文件，每份最多 10 MiB。
3. 点击“解析”，刷新列表确认解析完成，再点击“索引”；刷新确认可检索。
4. 输入原文中的词句检索，打开结果查看文件名、行号与原文。

上传、解析、索引是独立状态。提交成功只表示任务已排队；失败会显示错误，修正文件后可重试。同库重复内容会明确拒绝，同名不同内容保留为不同文档。删除会同时移除本地数据库中的原文、解析文本与检索块；已有备份不受影响。

## 实际范围

- **单机、单账户**：资料库之间用于整理文档，不是多用户权限隔离。密码以加盐散列保存；登录凭据只保留在页面内存中，退出会请求服务端注销。
- **关键词检索**：基于已索引的本地原文返回片段和行号，支持中文词句；没有向量语义检索、模型问答或生成答案。无匹配时返回空结果。
- **文本优先**：Markdown 作为纯文本展示，不执行内嵌 HTML。暂不支持 PDF、Office、扫描件、OCR 或多模态。
- 资料与索引保存在本机独立数据目录；运行时不向 Yuxi、外部模型或其他 Agent 系统发送资料。
- 原型适合个人小规模文本资料；大量文件的吞吐、长期运行和高并发没有完成容量验收。不作为多人公网服务使用。

## 配置与数据

默认端口为 `4184`；默认数据目录为仓库内 `.runtime`，数据库文件为 `library.sqlite`，该目录已被 Git 忽略。文件按仓库位置定位，不依赖启动终端所在目录。可选设置：

```sh
LIBRARY_PORT=4194 LIBRARY_DATA_DIR=/absolute/path/to/private-data node server.mjs
```

Windows PowerShell：

```powershell
$env:LIBRARY_PORT = '4194'
$env:LIBRARY_DATA_DIR = 'C:\private-library-data'
node server.mjs
```

`.env.example` 只说明变量，程序不自动读取 `.env`。旧版 `YUXI_LIBRARY_UPSTREAM` 已不再使用。

**备份**：先停止服务，再复制完整数据目录到安全位置。还原时同样先停止服务，再使用备份目录启动。数据包含账户和原文，应按私人资料保管；本版本不提供忘记密码恢复或在线备份界面。退出账号不删除资料，重新登录后可继续访问。

异常关机可能留下数据目录内的 `server.lock`。先确认该目录没有任何运行中的资料库进程，再移除这一个锁文件并重新启动；不要删除数据库。未完成任务会显示为处理失败，可以重新提交。

更新前分别备份源码版本与数据。数据库删除不等于对磁盘、系统快照及已有备份进行安全擦除。

## 检查与交付

```sh
node scripts/doctor.mjs
node scripts/test.mjs
node scripts/build.mjs
```

环境检查验证 Node 与临时 SQLite 读写；测试使用独立临时目录和无敏感样本，验证真实本地 HTTP/存储生命周期及 UI 状态；构建检查页面语法并生成静态文件 SHA256 清单。结果与未验证项见 [验收记录](docs/ACCEPTANCE.md)，过程见 [工作日志](docs/WORK_LOG.md)。

交付给别人时发送本仓库地址或源码包，让对方在自己的电脑创建账户；不要把 `.runtime`、真实配置、密钥和私人文档混入源码。GitHub 提供源码下载，本地服务仍需对方自行启动。
